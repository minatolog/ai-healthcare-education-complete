# Project Requirements

## Target Users

Years 8-12 students with little or no prior machine learning knowledge.

## Core Requirements

- Interactive browser-based educational website
- Guided workflow explaining AI predictions using healthcare data
- Support for multiple healthcare data modalities
- Comparison between single-modality and multimodal predictions
- Feature / biomarker importance visualisation
- QR-code integration with physical workshop cards or props
- Clear instructions for students
- Example or synthetic datasets
- Workshop materials for students and facilitators
- Functional and usability testing
- Structured and documented source code

## Data Modalities

Potential healthcare data modalities include:

- Clinical information
- Medical images
- Molecular or genomic information

The final datasets and modalities will be confirmed after consultation with the client.

## Technology

The technology stack has not yet been finalised.

Technical decisions will be made after team discussion and client consultation.
