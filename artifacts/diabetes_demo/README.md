# Diabetes Model Demo Artifacts

These files are generated by:

```bash
.venv/bin/python -m services.diabetes_model.generate_demo_artifacts
```

The generator uses a deterministic balanced selection of 20 training patients,
then the standard 10-patient validation and 10-patient test split. The outputs
demonstrate the complete ML flow for the proposal and backend handoff.

They are not clinical results and are not representative of real diabetes
prevalence or diagnostic performance. A student's different training selection
will produce different model scores and metrics.
